Los números de esta película

Ejemplo didáctico coherente de una cabeza, dmodel = dk = 4 y dv = 2. Una palabra representa un token para simplificar. Los pesos están elegidos a mano; no son los de un modelo entrenado. El bloque usa post-LayerNorm, γ = 1, β = 0, ε = 10⁻⁵ y sesgos cero.

La última escena de generación es una demostración conceptual separada: el vector del bloque no es todavía una palabra.
